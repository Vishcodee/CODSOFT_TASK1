# CodSoft Data Analytics Internship - Task 1: Data Cleaning & Preprocessing

## Overview
This project handles the inspection, data cleaning, and preprocessing of raw customer retail transaction records.

## Key Operations
- Identified and removed duplicate records.
- Handled missing customer and invoice identifiers.
- Converted date-time strings to native Pandas datetime format.
- Screened invalid age values and imputed missing values using median statistics.
- Exported the standardized output as `cleaned_retail_data.csv`.
